About Me

Building Platforms that Deliver Real Value

Ahmed Tarek is a Full Stack Developer focused on building platforms that deliver real value to users and communities. With strong experience in frontend development, Python programming, and backend frameworks like Django, he enjoys turning ideas into fully functional digital platforms.

Ahmed is also the founder of AeroScript (AS), an experimental programming language project aimed at creating a new developer-friendly scripting environment.

In addition to web development, he builds Discord bots using Python, creating automation tools and custom features for online communities. He is known for his creative ideas, logical thinking, fast learning ability, and strong problem-solving skills, and he consistently focuses on building high-quality solutions.
